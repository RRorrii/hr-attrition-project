# 📊 Система прогнозирования текучести кадров (HR Attrition Prediction)

Проект посвящен разработке системы анализа и прогнозирования риска увольнения сотрудников на основе открытого HR-датасета с использованием моделей машинного и глубокого обучения (нейронные сети).

## 🎯 Цели проекта
1. Провести разведочный анализ данных (EDA) и выявить ключевые факторы, влияющие на увольнение.
2. Подготовить данные и обучить модели (Logistic Regression, Random Forest, Neural Network).
3. Оценить качество моделей с помощью метрик (Precision, Recall, F1, ROC-AUC).
4. Разработать демонстрационное веб-приложение (Streamlit) для визуализации прогнозов и HR-аналитики.

## 🛠 Стек технологий
* **Язык:** Python 3.10+
* **Анализ данных:** Pandas, NumPy
* **Визуализация:** Matplotlib, Seaborn
* **Машинное обучение:** Scikit-learn, PyTorch
* **Веб-интерфейс:** Streamlit
