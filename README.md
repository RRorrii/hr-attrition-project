# 📊 Система прогнозирования текучести кадров (HR Attrition Prediction)

Проект посвящен разработке системы анализа и прогнозирования риска увольнения сотрудников на основе открытого HR-датасета с использованием моделей машинного и глубокого обучения (нейронные сети).

## 🎯 Цели проекта
1. Провести разведочный анализ данных (EDA) и выявить ключевые факторы, влияющие на увольнение.
2. Подготовить данные и обучить модели (Logistic Regression, Random Forest, Neural Network).
3. Оценить качество моделей с помощью метрик (Precision, Recall, F1, ROC-AUC).
4. Разработать демонстрационное веб-приложение (Streamlit) для визуализации прогнозов и HR-аналитики.

## 📁 Используемый датасет
* **Название:** IBM HR Analytics Employee Attrition & Performance
* **Источник:** Kaggle
* **Описание:** Датасет содержит 1470 записей о сотрудниках с 35 признаками (возраст, зарплата, стаж, переработки и т.д.). Целевая переменная — `Attrition` (уволился/остался). Данные обезличены.

  ## 🚀 Как запустить проект

Выполните следующие шаги в терминале вашей IDE (PyCharm, VS Code) или командной строке:
```bash
1. Клонируйте репозиторий:
git clone https://github.com/RRorrii/hr-attrition-project.git
cd hr-attrition-project

2. Установите необходимые зависимости:
pip install -r requirements.txt

3. Запустите скрипт подготовки данных (создаст обработанные CSV и скалер в папке data/processed):
python src/data_preprocessing.py

4. Обучите нейронную сеть (модель сохранится в папку models):
python src/train.py

5. Запустите демонстрационное веб-приложение:
streamlit run app/streamlit_app.py
